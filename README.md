# Review of Cyber-Physical Security in Modern Power Grids: From False Data Injection Attacks to Active Defense Mechanisms

## Abstract : 
The evolution of the legacy power grid into a smart Cyber-Physical System (CPS) has opened up new possibilities in remote control and distribution but at the same time it has also introduced an entirely new frontier of remote attacks. The pivotal attack on Ukraininan power grid to cause widespread blackout was a wake up call about the realization of these new type of attacks. \
In this review paper we analyze the evolution of cyber threats and corresponding defense mechanisms within the smart grid in the past decade and half. We begin with False Data Injection Attacks (FDIA) targeting State Estimator Mechanisms in the early days and examine how the industry has shifted toward more Machine Learning (ML) based anomaly detection systems that can detect in real time utilizing Deep Learning (DL) and Recurrent Neural Networks (RNNs). We also review state-of-the-art paper active defenses like Moving Target Defense (MTD) which has become necessary to address the growing attack surface because of Distributed Energy Resources (DERs) and Photovoltaic (PV) systems. Finally we discuss the emerging field of validating defensive frameworks using Cyber-Physical testbeds and identify critical research gaps regarding scalability and real-time implementation in next-generation power systems.
